# 💸 BagiRata AI - Smart Bill Splitter

Aplikasi web inovatif berbasis AI untuk membantu pembagian tagihan (patungan) secara otomatis hanya dengan mengunggah foto struk belanja/makan. Tidak ada lagi drama hitung manual!

## 🚀 Fitur Utama
- **AI Vision OCR**: Membaca data menu dan harga langsung dari foto struk menggunakan Google Gemini AI.
- **Smart Splitting**: Menghitung pembagian pajak (PB1), *service charge*, dan pembulatan secara otomatis dan adil.
- **Neubrutalism UI**: Desain antarmuka yang modern, berani, dan responsif.
- **WhatsApp Integration**: Hasil perhitungan bisa langsung disalin dengan format rapi untuk dibagikan ke grup WhatsApp.
- **Dark Mode**: Dukungan mode gelap untuk kenyamanan mata.

## 🛠️ Tech Stack & Bahasa
Aplikasi ini dibangun menggunakan teknologi modern:

- **Frontend**: [React.js](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Bahasa**: [JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript) (83.7%), [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS) (14.6%), [HTML](https://developer.mozilla.org/en-US/docs/Web/HTML) (1.7%)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/)
- **AI Engine**: [Google Gemini 2.5 Flash API](https://ai.google.dev/)
- **Deployment**: [Vercel](https://vercel.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 📖 Cara Penggunaan
1. Akses aplikasi melalui tautan di bawah.
2. Unggah foto struk belanja yang jelas.
3. Masukkan instruksi pembagian (contoh: "Ridho bayar Gacoan, Fahmi bayar Es Teh").
4. Klik **"PROSES DENGAN GEMINI ⚡"**.
5. Salin hasil perhitungan dan kirim ke grup tongkrongan!
